## Reproducibility and remaining limits

Use `adapters/formal_conjectures.py` with the pinned revision recorded in `data/manifest.json`; see `data-contract.md`. `npm run validate:data` checks hashes, source spans and reference closure. Python tests re-extract every record from preserved source. These checks establish transcription/integrity, not Lean correctness or current open status. Semantic duplicate review, expert theorem/formulation review, status reconciliation and broader licensed-source coverage remain future work.

`python scripts/audit-access.py` repeats only the explicit bounded metadata probes. It overwrites the dated receipt and therefore should accompany an intentional audit update, not an unattended refresh. Network observations can differ by client; both initial web-reader failures and successful local probes are recorded instead of presenting either as universal availability.
